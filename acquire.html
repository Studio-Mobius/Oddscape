Start a Project
Acquire an existing terrain study from the Oddscape Archive or commission a custom terrain model for your own site. Terrain packages can include high-resolution visualisations, LiDAR-derived terrain models, AR-ready USDZ files, hillshade studies, REM analysis and bespoke landscape interpretation.

How It Works

Whether you need a terrain model for a planning presentation, heritage project, landscape study, educational resource or personal interest, the process is straightforward:

Browse the Archive

Choose from existing Oddscape terrain studies available for licensing.

Request a Site

Provide a location, grid reference or project boundary for a custom commission.

Receive a Quote

Pricing is based on site size, data availability, outputs and project complexity.

Approve the Project

Once approved, terrain processing and visualisation work begins.

Receive Your Package

Outputs can include imagery, AR models, terrain meshes, DEMs, REMs and supporting material.

Use With Confidence

Licences are issued for named projects, organisations or educational use as appropriate.

Tell Me About Your Project

Licence ID generated after confirmation. QR access may be supplied, but the licence is attached to the named client, organisation or project.

Usage & Licensing

Oddscape terrain packages are licensed for named project use only. Redistribution, resale, stock upload, public re-hosting, or reuse on unrelated projects is not permitted without written permission.


Data attribution remains subject to original open data provider terms where applicable. Oddscape supplies interpretation, processing, visualisation and AR-ready terrain outputs.
